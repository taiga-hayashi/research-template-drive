# src/ — 共通実装

## 役割

複数の実験・解析から再利用する処理を一元管理する。

## 置くもの

モデル・問題定義・入出力処理・集計関数・パス読込・梱包処理。

## 置かないもの

計算結果、checkpoint、図、仮想環境、実験ごとの実装コピー。

## ルール

機能が分かるsnake_caseのモジュール名にする。実験の差分はexperiments/、コマンド入口はscripts/へ分ける。既存関数を確認してから追加し、変更した機能に応じてtests/で確認する。

## 配置・利用例

```text
research_paths.py: 端末別パス読込
artifact_package.py: 梱包・検証・取得・復元
```

[全フォルダの案内](../docs/FOLDER_GUIDE.md)を参照する。実際の研究固有ルールはAGENTS.mdと対象studyの仕様に従う。
