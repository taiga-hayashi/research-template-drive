# notes/ — 日付単位の研究ノート

## 役割

何を目的に実施し、何を観測し、どう考えたかを記録する。

## 置くもの

YYYY-MM-DD.md、図・run・analysis_id・Driveパッケージへの参照。

## 置かないもの

生データやログの大量コピー、根拠のない結果、固定ルールの重複記載。

## ルール

TEMPLATE.mdをコピーし、目的・実行・観測・解釈・限界・次の作業を分ける。同日の記録は追記し、観測事実と仮説を区別する。日時は日付基準を明記する。UTCのrun_idを日本の日付のノートへ参照してもよい。

## 配置・利用例

```text
TEMPLATE.md
YYYY-MM-DD.md
```

[全フォルダの案内](../docs/FOLDER_GUIDE.md)を参照する。実際の研究固有ルールはAGENTS.mdと対象studyの仕様に従う。
