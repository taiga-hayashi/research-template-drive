# tests/ — 必要な検証コード

## 役割

共通処理の正しさと、破損・上書き等を防ぐ動作を確認する。

## 置くもの

test_*.py、小さな合成入力、境界・失敗・復元のテスト。

## 置かないもの

実研究の大容量データ、秘密情報、テストのためだけに更新した実験原本。

## ルール

一時領域の合成データで検証する。実験結果に合わせて許容誤差を緩めず、構造テスト・小規模検証・本実験の成功を区別する。既存ローカル環境で実行し、環境を勝手に更新しない。

## 配置・利用例

```text
python -m unittest discover -s tests -v
```

[全フォルダの案内](../docs/FOLDER_GUIDE.md)を参照する。実際の研究固有ルールはAGENTS.mdと対象studyの仕様に従う。
