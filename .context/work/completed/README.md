# .context/work/completed/ — 完了作業の記録

## 役割

約束した範囲を検証して完了した作業の根拠を残す。

## 置くもの

YYYY-MM-DD-<task_id>.md。

## 置かないもの

実行中・検証待ちの作業を完了扱いで移したもの。

## ルール

必要な計算・検証・保存・解析の完了を確認してactive/から移す。未実施・対象外と理由も残す。過去の記録を黙って書き換えず、修正は追記して出典を示す。

## 配置・利用例

```text
YYYY-MM-DD-<task_id>.md
```

[全フォルダの案内](../../../docs/FOLDER_GUIDE.md)を参照する。実際の研究固有ルールはAGENTS.mdと対象studyの仕様に従う。
