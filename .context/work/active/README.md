# .context/work/active/ — 進行中の作業

## 役割

未完了の計算・検証・保存・解析と次の手順を残す。

## 置くもの

<task_id>.mdに目的・固定条件・ジョブID・実施済みと根拠・未確認・再開方法。

## 置かないもの

原本データ、秘密情報、投入済みなのに完了とした記録。

## ルール

task_idは内容が分かる名前にする。同じ作業の記録を重複作成しない。確認日時と状態を更新し、残る検証やDrive保存も明示する。

## 配置・利用例

```text
<task_id>.md
```

[全フォルダの案内](../../../docs/FOLDER_GUIDE.md)を参照する。実際の研究固有ルールはAGENTS.mdと対象studyの仕様に従う。
