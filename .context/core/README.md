# .context/core/ — 安定した研究固有情報

## 役割

目的・問題・正式保存先・変更禁止条件等を短くまとめる。

## 置くもの

project.mdと研究固有ルールへの参照。

## 置かないもの

一時的なジョブ状態、日々の進捗、コマンド出力の全文。

## ルール

既存の科学的条件と出典を確認して記入する。テンプレートの例を実研究の事実として残さない。個人パスはローカル設定へ分離する。

## 配置・利用例

```text
project.md
```

[全フォルダの案内](../../docs/FOLDER_GUIDE.md)を参照する。実際の研究固有ルールはAGENTS.mdと対象studyの仕様に従う。
