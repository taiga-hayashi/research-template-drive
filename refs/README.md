# refs/ — 参考文献と外部資料

## 役割

参考にした論文・ソフトウェア・仕様の出典を管理する。

## 置くもの

書誌情報、URL、引用キー、確認した版・commit、読書メモ。利用可能な範囲の資料。

## 置かないもの

実験結果、認証情報、公開可否を未確認の文献PDFをPublic GitHubへ登録すること。

## ルール

引用キーや著者年等で識別する。ソフトウェア参照は版・commitを残す。Drive内の保管とGitHub公開を区別し、共有するファイルを確認する。

## 配置・利用例

```text
references.bib
reading-notes.md
```

[全フォルダの案内](../docs/FOLDER_GUIDE.md)を参照する。実際の研究固有ルールはAGENTS.mdと対象studyの仕様に従う。
