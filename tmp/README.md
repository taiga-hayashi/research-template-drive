# tmp/ — 一時作業

## 役割

一時生成物を正式な実験・解析成果と分ける。

## 置くもの

Drive外の一時領域に作るscratch、途中変換物、確定前の作業ファイル。

## 置かないもの

唯一の原本、正式なrun、必要checkpoint、保存すべき研究ノート。

## ルール

実際の一時領域はDrive外にする。このフォルダは説明用であり、Drive内に大量生成しない。再現に必要なファイルは確定して所定の保存先へ移し、検証前の原本削除と混同しない。

## 配置・利用例

```text
<Drive外の一時領域>/<task_id>/...
```

[全フォルダの案内](../docs/FOLDER_GUIDE.md)を参照する。実際の研究固有ルールはAGENTS.mdと対象studyの仕様に従う。
