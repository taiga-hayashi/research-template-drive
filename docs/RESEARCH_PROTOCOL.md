# 比較条件と探索・確認実験

## 比較を始める前に

`templates/COMPARISON_CHECKLIST.md`へ各手法の条件と出典を記入する。「同じ」と書くだけでなく、設定ファイル・初期データchecksum・seed対応表等を示す。差を意図した比較では差分と解釈できる範囲を記録する。

問題定義・入力・制約・符号化・初期学習データ・真の目的関数の評価予算・学習条件・探索条件・コード版を確認する。cycleと評価回数、固定データでの予測診断と再学習を含む最適化を混同しない。比較のために既存実験条件を黙って変更しない。

失敗run・未完了run・対象外runを区別し、除外理由と必要件数を残す。有利なseedだけを選ばない。平均/中央値、SD/SE/CI/IQR、paired比較・多重比較等は研究目的とデータに応じて決め、特定の統計手法を全研究へ強制しない。

## 探索実験と確認実験

`templates/STUDY_PROTOCOL.md`にphaseをexploratory / confirmatory / diagnosticから選んで記録する。探索は仮説や条件の候補を探すために使う。探索で見つかった差を、独立した確認が済んだ証拠と扱わない。

確認実験では実行前に次を固定する。

- 検証する仮説、主要指標、比較対象とcontrol
- 問題・条件・モデル・予算・除外基準・必要件数
- 探索に使っていないseedまたは独立データと、その独立性の確認方法
- 集計・検定・不確実性の表示、停止・失敗時の扱い
- 固定したprotocolの版・日時・checksum

実行後に条件・指標・seedを変更したら、変更理由と版を残し、事前固定した確認と区別する。独立性を確保できなければ探索・追加診断として報告する。仮説、観測結果、解釈、未確認の一般化を別々に記録する。
