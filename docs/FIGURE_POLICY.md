# 研究ごとに揃える図の設定

`config/figures.example.json`を`config/figures.json`へコピーして研究の共通設定を記入する。model_stylesはモデル名ごとの色・線種・マーカーを記録し、関連図の既存のモデル色を維持する。相互作用のクラスや連続量のカラースケールを、モデル識別色で上書きしない。

PNG/PDFは同じ相対名で保存する。必要な各パネルは独立して描画し、統合図の切り抜きで代用しない。タイトルと図下の注釈は既定で表示せず、必要なら用途に応じて変更する。PNGだけでなくPDFも表示確認する。

解析ごとのanalysis_config.jsonから、共通設定の保存先・SHA-256と、その解析での変更を参照する。実際に使った設定を解析結果へsnapshotとして残す。モデルの採用・除外、run/seedの集計単位、平均/中央値、SD/SE/CI/IQR、cycleと評価回数、checkpoint位置と強調の意味を設定とREADMEに記録する。表示設定は共通設定へoverridesを再帰的に適用する方針とする。集計単位・中心値・不確実性の最終指定はanalysis_config.jsonのaggregation、対象run・checkpoint位置はselectionを正とし、共通設定やoverridesに矛盾する値を残さない。

共通設定は記録用の雛形であり、既存の作図コードへ自動適用されない。各解析スクリプトが読み込むか、記録と一致するよう明示的に設定する。設定を置いただけで図が検証済みと判断しない。

## 表示確認

凡例とデータの重なり、軸・単位、ラベル切れ、誤差の意味、モデル色、全体図と独立パネルの一致を確認する。重なりで比較できない場合は全比較を保持しつつ拡大図を追加する。異なるseed数や未完了runを含む図は対象範囲を明示する。

## NotebookとPythonによる実行

[解析・作図の運用](ANALYSIS_WORKFLOW.md)に従い、plot.ipynbとplot.pyを必ずセットで用意する。Notebookの各図に読み方をMarkdownで記載し、実データから再生成したPNG/PDFとセル出力を残す。保存先は各分類直下のpdf/・png/・csv/とし、版番号フォルダを作らない。
